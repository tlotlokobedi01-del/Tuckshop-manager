# Tuckshop-manager
A Java console application that helps a small Botswana tuckshop owner manage stock, record sales, process different payment methods, and view daily sales summaries.

# 🏪 Tuckshop Manager – Botswana Local Business System

## Project Overview

**Domain:** Business & Informal Trade – Tuckshop Inventory and Sales Management

**Local flavour / cultural grounding:**  
Tuckshops are everywhere in Botswana – from school corners to bus ranks in urban and rural villages. This system solves a real problem: keeping track of stock and sales without expensive point-of-sale hardware

## Concept Note

### Problem Statement
Small tuckshop owners in Botswana often rely on handwritten ledgers or memory to track stock and sales. This leads to stockouts, missed profits, and difficulty knowing which products sell best. Our app provides a free, simple, offline solution.

### Target Users
- Tuckshop owner / operator
- Shop assistant (basic training assumed)

## Core Features (Planned)
1. Add new product to inventory (name, price, quantity in stock)
2. Record a sale– select product, enter quantity, choose payment method
3. View current inventory– see stock levels and low-stock warnings
4. Generate sales report – total revenue, items sold, popular products
5. Update stock – restock items or adjust prices
6. Exit – clean program termination
